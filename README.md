#  Paleta-de-colores-Henry 🎨

Aplicación web interactiva desarrollada para generar paletas de colores aleatorias, personalizar la cantidad de colores y copiar sus códigos fácilmente al portapapeles.


# Características

- Generación de paletas aleatorias de **6, 8 o 9 colores**.
- Alternancia entre formatos de código **HEX** y **HSL**.
- Copia directa al portapapeles haciendo clic en cualquier tarjeta.
- Notificación flotante de confirmación al copiar.
- Accesibilidad con teclado (`Tab`, `Enter` y `Espacio`)


#  Tecnologías

- **HTML5:** Estructura semántica.
- **CSS3 / SCSS:** Estilos modernos con Grid y Flexbox.
- **JavaScript (ES6):** Lógica del DOM, eventos y Clipboard API (`apps.js`).
- **Git & GitHub:** Control de versiones y despliegue.
